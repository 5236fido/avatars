ÉTAPE 1 · PRÉPARATION

Créez votre personnage avec l’IA

Avant de concevoir votre carte individuelle, générez une image de votre personnage à partir de quelques photographies. Vous pouvez utiliser n’importe quel outil d’IA capable de générer des images; ChatGPT est recommandé pour ce travail.

  1. 01

    Préparez 2 à 4 photos du sujet

    Choisissez des photos nettes prises sous différents angles. Pour une meilleure ressemblance, incluez au moins une vue de face et une vue de biais.

    ✦ Privilégiez un visage bien éclairé et clairement visible.
  2. 02

    Téléchargez le guide d’instructions

    Ce document explique à l’IA comment créer l’image de votre personnage et présente les options d’uniformes.

    Télécharger le guide PDF

  3. 03

    Choisissez un uniforme

    Consultez les cinq uniformes numérotés de 1 à 5 dans le guide téléchargé, puis choisissez celui que portera le personnage.

  4. 04

    Demandez à l’IA de créer l’image

    Ouvrez un nouveau clavardage avec l’IA et joignez les éléments suivants :

    ▧2 à 4 photosImages du sujet
    ▤Guide PDFDocument de l’étape 2

    Dans le message, indiquez uniquement le numéro de l’uniforme choisi, par exemple :

    Uniforme #4

    Aucune autre instruction n’est nécessaire.

✓

Une fois votre image générée et enregistrée, passez à l’onglet 2. Carte individuelle pour créer votre carte.

GUIDE PRATIQUE

Afficher le fond d’écran dans Chrome

Voici comment configurer votre fond d’écran dans Chrome sur un ordinateur aux autorisations restreintes, comme ceux de Rogers.

01

Après avoir téléchargé le fond d’écran, ouvrez les « Téléchargements récents » dans Chrome et cliquez sur le fichier pour l’ouvrir.

02

Une fois le fichier ouvert, faites un clic droit, puis choisissez « Copier en tant que chemin d’accès ».

03

Ouvrez une nouvelle fenêtre Chrome.

✓
04

Dans le coin inférieur droit de la nouvelle fenêtre, cliquez sur « Personnaliser Chrome » (icône de crayon).

05

Dans le panneau latéral, cliquez sur « Modifier le thème ».

06

Sélectionnez « Importer une image ».

07

Si un ou deux messages d’erreur indiquent que vous ne disposez pas des autorisations nécessaires pour accéder aux fichiers de l’ordinateur, cliquez sur « OK ».

✓
08

Dans le champ de saisie, collez le chemin d’accès copié à l’étape 2, puis validez.
